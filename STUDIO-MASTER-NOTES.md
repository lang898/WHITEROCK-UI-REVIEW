# WHITEROCK Google Studio Visual Master

This folder preserves the Google AI Studio export as the visual and interaction master for the WHITEROCK website.

## Direction

- Preserve the current page hierarchy, hero proportions, typography, spacing, cards, configurators, calculators, navigation, and motion language.
- Future content work should replace text, data, links, and imagery inside the existing design instead of simplifying or rebuilding the layout.
- The separate `google-studio-react-review` folder remains a clean technical backup and is not the visual master.

## Publication Gate

This export is a design review build, not publication approval. Before production launch:

- Replace temporary external or stock imagery with approved local WHITEROCK assets.
- Verify all company claims, certifications, production figures, tariff statements, prices, MOQs, lead times, tolerances, timelines, and social statistics with the owner.
- Keep generated or illustrative imagery visibly labeled wherever it is used.
- Replace the local-storage admin demo with the approved Git-based CMS workflow before relying on it for production content management.
