# WHITEROCK Hybrid Design Version

This version combines two references:

- Google Studio: deep B2B content, RFQ and sample flows, product/color exploration, configurators, technical tools, and rich page coverage.
- whiterockstone.com: quiet editorial spacing, white gallery presentation, serif display type, forest-green actions, restrained borders, and image-first storytelling.

The Google Studio visual master and the clean review version remain unchanged in their own folders.

## Review Status

This is a design review build. Temporary external imagery and any commercial, certification, tariff, capacity, pricing, lead-time, or tolerance claims still require owner approval before publication.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```
